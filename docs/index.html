How it works

One script, run once for each PDF you drop.

01

Drop

Drag one or more PDFs onto the Dock icon. Multi-file drops run in one pass, no restart between them.

02

Extract

Pages with a text layer use native extraction. Pages with almost no text are treated as scans and run through OCR.

03

Done

A .md file with the same name is saved beside each PDF, and a macOS notification confirms it.

Why it's built this way

A small tool that stays out of the way.

Offline

Nothing leaves your Mac. No API calls.

Windowless

No app UI, no import step. Just the Dock icon.

Per-page OCR

Mixed PDFs work. OCR text is inserted at the right page position.

Free

No accounts, no subscription, MIT license.

The output

Each page is marked with an HTML comment saying whether it came from native text or OCR, so you can spot pages worth double-checking.

Install

Needs macOS, Homebrew and Python 3. Run the command at the top of this page. The installer, install.sh, does this and nothing else:

  1. Installs Tesseract with Homebrew, if it is missing.
  2. Installs pymupdf, pytesseract and pillow with pip, for your user only.
  3. Copies mdrop.py to ~/Applications/MDrop/ and builds ~/Applications/MDrop.app on your Mac.

Last step is yours: open ~/Applications in Finder and drag MDrop.app onto your Dock. The app is built locally rather than downloaded. macOS may still ask to allow notifications the first time you drop a PDF.

Known limits (v1)

Stated up front so nothing surprises you.

  • OCR output is flat text with no heading structure.
  • Tables on scanned pages are not rebuilt as Markdown tables.
  • Large PDFs with many scanned pages are slow, and there is no progress bar.
  • No GUI beyond the Dock icon and a system notification, by design.
