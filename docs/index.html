Install

MDrop installs through Terminal, the app where you type commands. If you've never used it, that's fine. This needs a Mac.

Nothing leaves your Mac. MDrop itself never connects to the internet. The installer downloads Tesseract and three Python packages, and that's all it does. It's one short file, and you can read it first.

Already use Terminal? You need Homebrew and Python 3, then:

$git clone https://github.com/jasuschristsg/mdrop.git cd mdrop && ./install.sh
New to Terminal? Step-by-step guide6 steps

  1. Open Terminal

    Press ⌘ Space, type Terminal, and press Return. A window with a blinking cursor opens. To paste a command into it, press ⌘ V, then Return.

  2. Check what you already have

    Paste both lines and press Return:

    $brew --version python3 --version
    • brew shows a version number: good. If it says "command not found", install Homebrew first. It's a free tool that installs other tools. Open brew.sh, paste the command shown there, and follow the prompts. It asks for your Mac password, and nothing appears as you type. That's normal.
    • python3 shows "Python 3" and a number: good. If macOS offers to install developer tools, click Install, wait for it to finish, and run the line again.

  3. Get MDrop

    Option A: with git

    $git clone https://github.com/jasuschristsg/mdrop.git cd mdrop

    Option B: without git

    Open the GitHub page, click Code, then Download ZIP. Double-click the ZIP to unzip it. In Terminal, type cd and a space, drag the unzipped folder into the Terminal window, and press Return.

  4. Run the installer

    If you closed Terminal since the last step, reopen it, type cd and a space, drag the MDrop folder in, and press Return. Then:

    $./install.sh

    It installs Tesseract (the OCR engine, usually the slowest part), three Python packages, and builds the app in your own Applications folder. It's finished when you see "Done. MDrop.app is at".

  5. Put it in your Dock

    In Finder, press ⇧⌘ H to open your home folder, open the Applications folder inside it, and drag MDrop.app onto your Dock.

  6. Try it

    Drag any PDF onto the MDrop icon. A "Conversion complete" notification appears, and a .md file with the same name shows up beside the PDF. The first time, macOS may ask to let MDrop send notifications.

If something goes wrong

"brew: command not found" right after installing Homebrew

Close Terminal and open it again. If it still fails, scroll up in the old window: Homebrew prints a couple of "Next steps" commands at the end of its install. Run those.

"Permission denied" when I run ./install.sh

Run it through bash instead: bash install.sh.

I dropped a PDF and nothing happened

Run the converter yourself to see the error. Type python3 ~/Applications/MDrop/mdrop.py, add a space, drag your PDF into the Terminal window, and press Return. Whatever it prints is the problem.

macOS says it can't open MDrop

Open System Settings, go to Privacy & Security, scroll down and click Open Anyway, then confirm. The app is built on your Mac, so this is unlikely, but that's the fix if it happens.

See it work

You drop a PDF on the icon. MDrop copies the text from pages that have it and reads scanned pages with OCR. A .md file with the same name lands next to the PDF. This is my Mac.

report.pdf
Page 1 (text layer)
Q3 Summary
Revenue grew 12% year on year.

Page 2 (scanned image)
[photo of a signed page]
report.md
# report

<!-- page 1 (text) -->

Q3 Summary
Revenue grew 12% year on year.

<!-- page 2 (ocr) -->

Signed by the board on 14 March.

Real output from a two-page test PDF. Each page gets a comment saying whether it was read as text or by OCR, so you know which pages to double-check.

Questions

Is it safe?

MDrop itself never connects to the internet. The installer does, to download Tesseract and the Python packages. The code is open, and the installer is one short file you can read first.

Does it handle scanned PDFs?

Yes, page by page. Pages with real text are copied directly. Pages that are just images go through OCR. The catch: scanned pages come out as plain text, with no headings or tables.

Where does the file go?

Next to the PDF, with the same name and a .md ending. If a file with that name is already there, it gets replaced.

Why do I need Terminal?

MDrop isn't packaged as a downloadable app. The installer builds it on your Mac instead, which is why Terminal is involved.

How do I uninstall it?

This deletes the MDrop folder and the app, so check it before you paste it. Then drag the icon out of your Dock.

$rm -rf ~/Applications/MDrop ~/Applications/MDrop.app

Where it falls short

  • Scanned pages come out as plain text. No headings, and tables aren't rebuilt.
  • Big PDFs with lots of scanned pages are slow, and there's no progress bar. Give it a minute.
  • There's no window. If you want one, this isn't it.
  • Mac only.

Why I made it

Every PDF converter I found was either a window that handled one file at a time, or a website with no OCR for scanned pages. I wanted to drop files on an icon and get on with my day. So MDrop has no window, there's no account, and it's free under the MIT license.
