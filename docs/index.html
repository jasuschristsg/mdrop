MDrop is a small Mac app I built. Drag PDFs onto its icon in your Dock and a Markdown file shows up next to each one. No window to open, nothing to click through.

How it works

There's one script behind it. Here's what it does with each PDF you drop.

1

You drop

Drag one PDF or ten onto the MDrop icon in your Dock. They're all handled in one go.

2

It reads

If a page has real text, MDrop copies it. If a page is just a picture, like a scan, it reads the picture with Tesseract OCR instead.

3

You get a file

A .md file with the same name appears next to each PDF, and a notification tells you it's done.

This is real output from a two-page test PDF. Each page gets a comment saying whether its text was read directly or by OCR, so you know which pages to double-check.

Why I made it

Every PDF converter I found was either a window that handled one file at a time, or a website with no OCR for scanned pages. I wanted to drop files on an icon and get on with my day. So MDrop has no window. Nothing leaves your Mac, there's no account, and it's free under the MIT license.

Built by Jasper. The code is on GitHub, and the installer is one short file you can read before you run it.

Install

MDrop installs through Terminal, the app where you type commands. If you've never used it, that's fine. Every step is below, and you only paste what's in the grey boxes. Already comfortable there? The three lines at the top of this page are all you need.

  1. Open Terminal

    Press ⌘ Space, type Terminal, and press Return. A window with a blinking cursor opens. To paste a command into it, press ⌘ V, then Return.

  2. Check for Homebrew

    Homebrew is a free tool that installs other tools. MDrop uses it to get the OCR engine. Paste this and press Return:

    $brew --version

    If you see a version number, go to step 3. If you see "command not found", open brew.sh, paste the one command shown there, and follow what it prints. Then come back.

  3. Check for Python 3

    $python3 --version

    If you see "Python 3" and a number, you're set. On a Mac that has never had developer tools, macOS may offer to install them. Click Install, wait for it to finish, and run the command again.

  4. Get MDrop

    Option A: with git

    $git clone https://github.com/jasuschristsg/mdrop.git cd mdrop

    Option B: without git

    Open the GitHub page, click Code, then Download ZIP. Double-click the ZIP to unzip it. In Terminal, type cd followed by a space, drag the unzipped folder into the Terminal window, and press Return.

  5. Run the installer

    $./install.sh

    It installs Tesseract (the OCR engine, usually the slowest part), three Python packages, and builds the app in your own Applications folder. It's finished when you see "Done. MDrop.app is at". You can read the script first if you like.

  6. Put it in your Dock

    In Finder, press ⇧⌘ H to open your home folder, open the Applications folder inside it, and drag MDrop.app onto your Dock.

  7. Try it

    Drag any PDF onto the MDrop icon. A "Conversion complete" notification appears, and a .md file with the same name shows up beside the PDF. The first time, macOS may ask to let MDrop send notifications.

If something goes wrong

"brew: command not found" right after installing Homebrew

Close Terminal and open it again. If it still fails, scroll up in the old window: Homebrew prints a couple of "Next steps" commands at the end of its install. Run those.

"Permission denied" when I run ./install.sh

Run it through bash instead: bash install.sh.

I dropped a PDF and nothing happened

Run the converter yourself to see the error. Type python3 ~/Applications/MDrop/mdrop.py, add a space, drag your PDF into the Terminal window, and press Return. Whatever it prints is the problem.

macOS says it can't open MDrop

Open System Settings, go to Privacy & Security, scroll down and click Open Anyway, then confirm. The app is built on your Mac, so this is unlikely, but that's the fix if it happens.

Questions

Is it safe?

MDrop itself never connects to the internet. The installer does, to download Tesseract and the Python packages. The code is open, and the installer is one short file you can read first.

Does it handle scanned PDFs?

Yes, page by page. Pages with real text are copied directly. Pages that are just images go through OCR. The catch: scanned pages come out as plain text, with no headings or tables.

Where does the file go?

Next to the PDF, with the same name and a .md ending. If a file with that name is already there, it gets replaced.

Why do I need Terminal?

MDrop isn't packaged as a downloadable app. The installer builds it on your Mac instead, which is why Terminal is involved.

How do I uninstall it?

Paste this into Terminal, then drag the icon out of your Dock:

$rm -rf ~/Applications/MDrop ~/Applications/MDrop.app

Where it falls short

  • Scanned pages come out as plain text. No headings, and tables aren't rebuilt.
  • Big PDFs with lots of scanned pages are slow, and there's no progress bar. Give it a minute.
  • There's no window. If you want one, this isn't it.
  • Mac only.
